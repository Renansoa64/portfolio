Papercraft

De papeis para esculturas!

O papercraft (também conhecido como papel modelismo) é a arte de criar objetos tridimensionais a partir de folhas de papel, cartolina ou papel-cartão


Diferença para o Origami


Papercraft Utiliza moldes que você recorta, vincula (faz as marcas de dobra) e cola para montar a estrutura 3D.
Origami Tradicionalmente usa apenas uma única folha de papel dobrada, sem cortes ou uso de cola
